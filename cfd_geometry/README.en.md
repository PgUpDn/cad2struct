# CFD-Ready Vehicle Geometry (Organized by Vehicle)

[中文](README.md) | **English**

Geometry that can be used directly for external-aerodynamics CFD, extracted from three public repositories and grouped by vehicle. Every STL (including the triangulations of the STEP files) has been checked with `tools/stlcheck.py`: all are watertight with consistent normals, and all are in **meters**.

## Directory structure

```
cfd_geometry/
├── previews/overview.png           # preview mosaic of all configurations
├── tesla_model_s/
│   ├── polimi_openfoam/            # source ①  MIT   with wheels, baseline + 4 rear-wing configs, OpenFOAM case
│   │   ├── stl/                    #   5 STLs
│   │   └── openfoam_case/          #   blockMesh/snappy/simpleFoam dictionaries + Allrun
│   └── fluent_spoiler/             # source ②  MIT   body without wheels + spoiler
│       ├── step/                   #   original STEP (first choice for remeshing)
│       └── stl/                    #   STEP triangulation, plus wall surfaces extracted from the Fluent mesh
└── tesla_cybertruck/               # source ③  ⚠️ no license stated
    ├── standard_closed_bed/        #   each directory is a complete OpenFOAM 12 case
    ├── open_bed/
    ├── roof_rack/
    ├── roof_carrier_box/
    └── postprocessing/
```

## How to choose

- **For a ready-made Model S with wheels that runs with a single command**: use `polimi_openfoam/` and run `./Allrun <variant_name>`.
- **For clean CAD to mesh yourself (Fluent / STAR-CCM+ / OpenFOAM)**: use `fluent_spoiler/step/tesla_model_s_base.stp`. Note that this geometry has no wheels.
- **For a model with rotating wheels (MRF), or for comparing configurations**: use the four Cybertruck cases.

## Conversion tools (`tools/`)

| Script | Purpose |
|---|---|
| `stlcheck.py <stl…>` | Prints the triangle count, whether it is watertight, the number of bodies (shells) and the bounding box |
| `step2stl.py <in.step> <out.stl> <hmax_m> [hmin_m]` | Triangulates a STEP file into STL with gmsh (units mm → m) |
| `fluent2stl.py <mesh.msh.h5> <zone> <out.stl>` | Extracts one face zone from a Fluent HDF5 mesh and writes it as STL |
| `render_previews.py` | Regenerates all preview images and `previews/overview.png` (on a headless machine, use `xvfb-run -a python3 tools/render_previews.py`) |

Dependencies: `pip install trimesh numpy scipy h5py gmsh pyvista pillow` (gmsh also needs the system library `libglu1-mesa`; rendering on a headless machine needs `xvfb`).
